# Roadmap

Status: proposed sequence, not a delivery-date promise.

| Phase | Outcome | Exit condition |
|---|---|---|
| 0 — Project preparation | Documents, cloned/rebranded foundation, dependency upgrade preparation, agent handoff | Current state accurately documented; owner can review scope |
| 1 — Access foundation | Organizations, internal units, people, accounts and scoped responsibilities | Owner manually confirms cross-school boundaries and local approval |
| 2 — Local operation | Member profile/forms, departments, coordinator appointments, activity/participation | Pilot lead/member/coordinator can complete core work |
| 3 — Reporting | Cycles/templates, draft/review/release, higher review and completeness | Report versions reconcile and missing data is visible |
| 4 — Shared information | Targeted notices, resources/experience publication and moderation | Selected schools share approved content with private records protected |
| 5 — Pilot readiness | Localization, exports, operations, restore demonstration, training | Owner accepts agreed pilot scenarios; operational owner is named |
| Later | Assemblies, specialist department systems, deeper integrations/offline support | Separate requirement evidence and approval |

The MVP includes hierarchy, member access, departmental coordination, approved reporting and bounded sharing. A limited pilot validates these before countrywide rollout. Hosting/provider selection and exact pilot scale remain open. No fixed effort estimate is justified yet.
